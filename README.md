# Ricardo Mejia – Portfolio Website

This repository contains the source code for my personal portfolio website. The site highlights my projects, skills, and experiences as a Mechatronics and Manufacturing Engineer with a strong focus on embedded systems, automation, and software development.  

Live Site: [https://ricardomejia.dev/](#) 

---

## Features  
- Animated red background with particle effects  
- Keyboard shortcuts for quick navigation  
  - `G` or `/` → Open quick navigation  
  - `T` → Toggle theme (light/dark)  
  - `?` → Open keyboard shortcut help  
  - `Esc` → Close dialogs  
- Responsive design with a mobile-friendly navigation menu  
- Resume download button  
- Experience and project sections designed for clarity and professionalism  
- Contact form integrated with Formspree  

---

## Tech Stack  
- HTML5 – structure  
- CSS3 – styling and responsive design  
- Vanilla JavaScript – interactivity, keyboard shortcuts, and particle effects  
- Formspree – backendless form submissions  
- GitHub Pages – hosting  

---

## Sections  
- Home – introduction with animated background  
- Skills – technical abilities  
- Experience – professional roles and internships  
- Projects – selected engineering and software work  
- Contact – email form for communication  

---

## Getting Started  
To run locally:  
```bash
git clone https://github.com/ricMejia1/portfolio.git
cd portfolio
open index.html   # or double-click index.html
```

To deploy:  
- Push changes to the `main` branch  
- Enable GitHub Pages in repository settings (root, `/main`)
